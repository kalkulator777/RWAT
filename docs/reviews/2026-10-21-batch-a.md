## Устаревшие утверждения SPEC (вход для новой спеки, партия F)

- **§2.1:** часы воспроизведения — снап только на тике со снимком, в тишине держатся на `newest + 20`, возобновившийся поток догоняется; пауза — и `/tick freeze`; «Поправка 2» — считается тиками с последнего снимка и до H9 не срабатывала; «замёрзший со скоростью — каждый тик» → один снимок при заморозке и затем раз в 10 тиков, всегда v = 0.
- **§2.2:** валидация сегментов теперь есть; дальний конец не прилипает к новому узлу ближнего, минимум 2 блока — после прилипания; маркер — ближайший, который игрок может ломать; права на размещение полотна, на перекраску и снос всей конструкции; правка мира вне захвата снимков; перепривязка — только к выжившему участку под поездом, иначе `Stranded`.
- **§6.11:** `/kill` или пустота ломают вагон из состава без предмета; у `TrackPathSpec` третий вариант `Stranded`.
- **§9.1, §9.8:** касающиеся зоны — один пол, **кроме как через закрытую внутреннюю дверь**; `FloorCheck` считает с закрытыми дверями, два новых предупреждения, входы — по всем кускам; цифры ручного пола плацкарта 4.10 / 2.97 / 1.13.
- **§9.5:** переход — через ближайшую **открытую** межвагонную дверь; смешивание камеры — на своих часах, зажато, сбрасывается.
- **§9.7:** свет на пульте прокручивается, неактивен вне управляющей кабины, «ожидание» до 2 с; 480×270 больше не самый тесный (320×240/256 — узкая компоновка); «Управляют из другой кабины» переносится.
- **§10.3:** звук запуска — только при настоящем запуске; дальности — и для звуковых событий; при нулевой громкости ничего не играет; перезапуск упавших петель; первый объявленный звук органа.
- **v1.5:** «сервер `collide` для игроков не зовёт» — зовёт, зажим для игроков на сервере пропущен намеренно; у запрета спешивания — разрешённые выходы; проём двери односторонний; ПКМ-выход — только новый клик, который никто не забрал; защёлка зажатой ПКМ — для всех выборов; ресинк ходьбы — подтверждение и переигрывание вместо «10 тиков стоим».
- Не описано вовсе: сброс клиентского состояния при выходе и смене мира (`RailsWheelsAndTrainsClient.clearLevel()`).

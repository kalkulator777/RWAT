### D7: устойчивая загрузка (после закрытия; ветка `worktree-agent-a66bed6ee551a7f83`)

Пункт 6 карты не был закрыт: при закрытии фазы выяснилось, что ни одно из четырёх мест не тронуто. Сделано отдельными коммитами, у каждого тест, который краснеет без правки (проверено откатом правки).

1. **Битый NBT рельсов — `5d11740`.** Узел или сегмент с повреждением пропускается с ошибкой в логе (что и почему), остальной граф грузится.
   - Чистая часть, `path/RailGraph`: `restoreNode`, `restoreSegment`, `restoreSwitchSelection`, `dropOrphanNodes` возвращают причину вместо исключения. Отказ: id не положительный или занят; позиция вне мира (NaN, ±3·10⁷); касательная узла или переопределение сегмента не конечный ненулевой вектор; нет узла A или B; оба конца в одном узле (петля, которую можно было построить до M19, — её касательные были NaN); знак конца не ±1; узлы в одной точке; кривая без конечной длины.
   - `ArcLengthTable` отказывает кривой без конечной длины сразу при построении, с сообщением. Раньше длина NaN доходила до `Math.clamp` в `tForS` (бросает на NaN-границе) и падало у первого, кто сэмплировал кривую.

Каждая пропущенная запись — строка `error` в логе с id и причиной, итог — одной строкой. Узлы, у которых не осталось сегментов, отбрасываются, настройки стрелок несуществующих узлов — тоже. Тест пинует половину графа: маршрут через пропущенный даёт `null`, маршрут по уцелевшим целый.
   - Тесты: `RailGraphRestoreTest` (12), `ArcLengthTableTest` (+1). Здоровый граф проходит проверки целиком, равный себе.
2. **Номер органа из 11+ цифр — `f4c9e39`.** `ObjectRole.control` больше не бросает `NumberFormatException`. Тест: `ObjectRoleTest` (+1).
3. **Плохая запись `rwat.packDirs` — `176f25d`.** Разбор списка вынесен в чистый `pack/PackDirs.parse`; запись, которая не путь, пропускается с предупреждением в логе (раз на изменение) и в `PackReport` (источник `PACKS`, пак `rwat.packDirs`, файл — запись, управляющие символы записаны кодом), остальные папки ищутся. 4. **Имена материалов с пробелами — `456cc89`.** Одно правило и одна функция, `MtlParser.materialName`: имя — вся остальная строка после ключевого слова, обрезанная, пробелы внутри сохраняются. Её зовут `ObjLoader` (`usemtl`) и `MtlParser` (`newmtl`); `ModelCheck` читает через них и согласен с игрой. Порт: `ir2rwat.material_name` (его `parse_mtl`); `floorgen.py` материалов не читает. Те же 12 случаев в `MaterialNamesTest` и `tools/tests/test_obj_names.py`. Пак MVP перегенерирован байт в байт (`diff -r`: 734 файла, без отличий), `GeneratedPackLoadTest` зелёный без правок.

**Решения агента** (на утверждение дирижёру):
- **Номер органа — не отказ, а насыщение.** Объект `THROTTLE_12345678901` остаётся органом, `id` держится на `Integer.MAX_VALUE`. Основания: `Control.id` нигде не читается, органы различает `key` с цифрами как написано; конвертер (`DOOR_KEY`, `WIDGET_KEY`, питоновские `int`) такое имя уже считает органом — «не орган» развело бы Java и Python; рычаг, названный автором, не должен молча стать декорацией.
- **Правило имени материала — Blender.** Сверено с исходниками Blender: нынешний экспортёр пишет имена материалов с пробелами как есть, импортёр читает `usemtl` и `newmtl` как остаток строки, обрезанный. Старый текст Wavefront («имена без пробелов») не противоречит: без пробелов все чтения совпадают. Любой пробельный символ после ключевого слова (раньше в MTL требовался пробел, не табуляция).
- **Что считается битым в графе** — перечень в п. 1. Намеренно не битыми считаются сегменты короче `MIN_SEGMENT_LENGTH` (в старых сейвах они были) и переопределения не единичной длины: они грузятся, как грузились.
- **Не помечаем сеть изменённой при пропуске.** Файл хранит прежнее, пока игрок не правит рельсы: не уничтожаем данные, которых не поняли; запись пропускается заново при каждой загрузке, ошибка видна в логе.
- **`rwat.packDirs` — предупреждение, не ошибка:** ни с одним паком ничего не случилось, не искалась одна папка. Запись обрезается `strip()`, а не `trim()`: `trim` молча съедал NUL на краях и делал путь из того, что им не было.

Итог: 777 тестов Java (было 752), 91 тест Python (было 89), `./gradlew build` зелёный, `validate_pack.py --self-check` — 0 замечаний, `gen_pack_docs.py --check` — актуален.

1. Тифон и свисток берут **второе число** диапазона `pitch`/`volume`: нажатая клавиша — это «полный ход» (`b3787c3`, `SoundLevels`).

3. **Спорный алиас достаётся меньшему id**, ошибку получают оба файла. **Тип грузится целиком или никак** вместе со своими `aliases` (`465ded6`).
4. **`/reload` с новой геометрией** (`188b4ac`):
   - состав держится за середину между крайними сцепками и остаётся на открытом пути;
   - ходячие из вагона, который перестал быть ходимым, выходят сбоку;
   - машинист, у которого пропало кресло, встаёт, как из кресла;
   - открытые двери следуют за своими id.
   Алиасы удалённым клиентам не синкаются: синк несёт только типы, снимки — уже разрешённые id. Пересборка ждёт конца `/tick freeze`, потому что составы не тикают, пока мир заморожен.
5. **Хеш пака** — без файлов на точку и мусора ОС (`__MACOSX`, `Thumbs.db`, `desktop.ini`). Сверка только предупреждает. Собственный клиент интегрированного сервера не сверяется: он читает файлы сервера (`71e1f1f`).
6. **Блок `rwat` в схеме обязателен** (`required: ["pack", "rwat"]`). Движок без него читает пак как формат 1 с предупреждением (`49be968`).
7. **`bogies`, `couplers`, `length` — расстояния вдоль вагона**, а не координаты: в обоих кадрах одни и те же, переводятся только точки и коробки (`ca59208`, `ObjFrame`).
8. **Пак только со стилями рельсов допустим**: ни загрузчик, ни отчёт не требуют типов вагонов.
9. **Ключи на `_` — комментарии** в рецепте и оверрайдах на любой глубине. Id, начинающийся с `_`, ключом назвать нельзя (`8b12d42`, `cce051a`).
10. **`group: null`** — по-прежнему «нет группы», но с предупреждением (`a648c3f`).
11. **Тип без модели на клиенте** — предупреждение в отчёте под паком «server» (`c10fa4e`).
12. **`fixed`-проём не получает бита открытия**, и анимация по его id не играет, даже в группе (`9e2bfcb`).
13. **Второе кресло тепловоза-примера** — у заднего пульта, `yaw` 180, ведёт назад (`69a3fca`).
14. После смены типа у вагона звуки дверей полсекунды молчат: иначе перестановка дверей после `/reload` звучала бы. Настоящая дверь в эти полсекунды не слышна (`f1c199b`).
15. В одиночной игре и у хоста LAN `/rwatc packs` выводит один общий отчёт. Проблема, найденная обеими сторонами, называется один раз (`c013e1e`).
16. Пак, отвергнутый по формату, всё равно назван в списке, но описательные поля замечаний не дают (`6528796`). Второй пак с тем же именем файла — ошибка в списке паков (`49be968`).
17. Список паков показывает только уже посчитанный хеш и не ждёт хеширования (`6fab5d6`).
18. Эвристики `floorgen` по-прежнему считают в кадре модели и округляют там, а переводят только на краях. Выведенная коробка совпадает с движком до последней цифры (`ca59208`, отсюда и числа вида 1.37475 ниже).

## Проверено в игре

- **`/reload`** (`188b4ac`, временная автосцена, одиночная игра, ЧМЭ3 + плацкарт):
  - на едущем составе изменены длина, тележки, пол и порядок дверей;
  - кресло убрано из-под сидящего машиниста;
  - тип плацкарта убран из-под ходящего игрока и возвращён.
- **По отчётам агентов дирижёру** (в сообщениях коммитов этого нет):
  - версия формата паков и сверка паков по хешам — на выделенном сервере;
  - `/rwat packs` — через RCON;
  - кресла 14 типов после перевода кадра — автосценой `stock`.

## Не проверено в игре

- Звук на слух: тифон и свисток с диапазоном пака, `trainVolume` выше 1.
- `/rwatc packs` и уведомления на клиенте: строка оператору, расхождение паков в чате и в отчёте.
- `/rwatc packs validate` — вместе с правкой о маркерах шарниров.
- Звук органа по точному виду.
- Проёмы `fixed` в группе дверей: бит, анимация, звук.
- Пак-пример целиком: ни одной сцены с ним — вагон, тепловоз, полувагон, стиль рельсов.
- D7: мир с повреждённым NBT рельсов. Логика отбора — в чистом `RailGraph.restore*`, под тестами; разбор тегов в `RailNetwork.load` (читает NBT, без Minecraft не запускается) и поведение состава, чей маршрут пропущен (`Consist.resolvePath` → `Stranded.UNPLACED`), в игре не видны.
- D7: строка в `/rwat packs` и в логе для плохой записи `rwat.packDirs` (`RwatPacks` грузит Minecraft).

## Устаревшие утверждения SPEC (вход для новой SPEC, F1–F2)

Каждое сверено с кодом.

- **§5.2:** «для N тележек — по ближайшему пивоту». В коде две: `IrStockModel` берёт первый и последний шкворень типа.
- **§5.5, шаг 5:** «уже загруженные составы держат старые экземпляры типов до перезагрузки мира» — после `/reload` составы берут новые типы на следующем тике. `SimpleJsonResourceReloadListener` — теперь `WagonTypeReloadListener` на `SimplePreparableReloadListener`, файлы читает сам, битый JSON попадает в отчёт. «Модель клиента всё ещё захардкожена» — модели приходят из паков, встроенного слоя типов нет.
- **§6.1:** в дереве пака нет блока `rwat` в `pack.mcmeta` (`format`, `name`, `version`, `authors`, `license`, `description`). В сконвертированном паке есть `RWAT_CONVERSION.txt`: источники, неймспейс, формат; это и маркер, без которого конвертер не заменит папку или zip.
- **§6.2:** «положил zip → перезапустил» — пак формата новее 1 или с битым `format` не подключается, ошибка видна в `/rwat packs`. Мультиплеер: при входе клиент сверяет паки с сервером по хешам. (D7) Запись `rwat.packDirs`, которая не путь, пропускается с предупреждением в логе и в `/rwat packs`, остальные папки ищутся.
- **§6.3:**
  - (D7) «Текстуры — из MTL»: имя материала — вся остальная строка после `usemtl`/`newmtl` (пробелы внутри сохраняются, как у Blender), а не первое слово.
  - «IR-ассеты ложатся в пак байт-в-байт» — кроме путей чужих паков, которые Minecraft не примет: файл переименовывается, строки `mtllib`/`map_Kd` и декларации переписываются.
  - «Всегда пропускаются `*HIDE*`» — кроме органов `WIDGET` (видны по значению) и голов сцепок `COUPLED_*` (видны по сцеплению).
- **§6.4:**
  - «алиас … отбрасывается с ошибкой в логе» — спорный достаётся меньшему id, ошибку получают оба файла, в отчёте пака; битый список алиасов отказывает всему файлу.
  - Парсер отказывает ещё на `null`, неверном типе (с путём поля) и геометрии.
  - Незнакомый ключ — предупреждение с подсказкой.
- **§6.5:** вернувшийся пак восстанавливает состав и по `/reload`, без перезагрузки мира.
- **§6.6:** OBJ по-прежнему разбирается лениво, но его ошибки видны без появления вагона в кадре: `/rwatc packs validate`.
- **§6.8:**
  - Ключи рецепта в тексте неполны. В `RECIPE_KEYS` есть ещё `overrides_dir`, `rail_exclude`, `rail_overrides`, `sound_defaults`, `id_strip_prefix`, `pack_dir`, `out`, `name`, `description`, `license`, `version`, `authors`. Ключи `_` — комментарии.
  - Не описан `--geometry`.
  - Пак собирается рядом и подменяется целиком (через временную папку).
  - 0 сконвертированных типов — отказ. Коды выхода 0, 1, 2.
  - Zip без маркера тоже не заменяется.
  - Свой корень у каждого источника — проверяемое правило, а не совет.
- **§6.10:** «`tile_length` (по умолчанию 1)» — не меньше 0.25, иначе стиль отвергается. Декларацию читает один разбор `RailStyleDecl`, для рендера и для полотна.
- **§9.1–9.2, §9.4:** разметка (зоны, двери, `cab.seats[].at`) в паке — в кадре OBJ, `WagonTypeParser` переводит её в кадр модели. Замеры ЧМЭ3 в §9.4 («кабина x ±1.44, z −5.5…−3.625», пол 2.311) — в старом кадре модели.
- **§9.5:** «Группы дверей … открываются и закрываются вместе» — кроме `fixed`: проём без створки бита не получает, его анимация не играет (`WagonType.doorsOpenedWith`). `""` и `null` — нет группы, `null` с предупреждением.
- **§9.6:** `objinfo` — «габариты в осях RWAT»: на самом деле в кадре OBJ. `--doors` выводит двери кодом конвертера по IR-пакам рецепта (`--recipe`).
- **§9.8:** многоугольники пола описаны как принятые — в коде только коробки (план — фаза 3).
- **§10.3:**
  - `trainVolume` выше 1 только поднимает тихие звуки до уровня файла, дальность не меняется.
  - Тифон и свисток берут второе число диапазона пака.
  - Звуки `controls` ищутся по виду органа (первый объявленный ключ этого вида), а не по ключу.
  - Вступление двигателя (`start`) играет только при настоящем запуске.
- **§10.4:** неизвестная IR `era` — предупреждение, у двигателя остаётся диапазон мода по умолчанию.
- **v1.5:** «`WagonType.Interior` — опциональный локальный AABB (модель-спейс, +Z вперёд)» — это список зон, а в паке — кадр OBJ. «NBT `Doors`» — теперь `OpenDoors`, список id открытых дверей; старая маска отбрасывается.

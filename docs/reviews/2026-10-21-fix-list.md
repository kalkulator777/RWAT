## Как работаем

- **Порядок:** A → B → C → D → E → F. B1 (защита регионов) можно вести параллельно с A — другие файлы. F2 (новая спека) — после A и B, чтобы описывать исправленное поведение.
- **Партия = PR.** Внутри — агенты параллельно на непересекающихся группах файлов. Opus — партии A–C, D1–D4, E4–E6, E10; Sonnet — D9, E1–E3, E7–E9. Я проверяю каждый дифф, собираю, гоняю тесты и автосцены и только потом сливаю.
- **Ворота для каждого пункта:** сборка и все тесты зелёные; для чистого кода — новый тест, который падал до исправления; для игрового — автосцена или снимок; комментарии и SPEC поправлены в том же коммите.
